# Fatihsenel Tap

## How do I install these formulae?

`brew install fatihsenel/tap/<formula>`

Or `brew tap fatihsenel/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "fatihsenel/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
